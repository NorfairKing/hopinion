If the file defines no `spec`, rename it so that its name does not end in `Spec.hs`.
Otherwise, make its export list exactly `(spec)`: `module Foo.BarSpec (spec) where`.
Move anything other modules import from it into a `.Gen` module of the -gen library if it is a generator, and otherwise into a test-suite module whose name does not end in `Spec`, such as `Foo.TestUtils`.
