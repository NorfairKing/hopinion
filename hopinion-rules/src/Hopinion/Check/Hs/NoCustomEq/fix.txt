If the instance compares every field, delete it and derive Eq: `deriving stock (Eq)`, `deriving newtype (Eq)` on a newtype, or `deriving stock instance Eq T` for a type from another module.
Otherwise, also write its comparison as a named function, such as `sameUserName :: User -> User -> Bool`, and use it wherever the old meaning is needed: `==` becomes a call to it, `elem x` becomes `any (sameUserName x)`, and `nub`, `group` and `delete` become `nubBy`, `groupBy` and `deleteBy`.
If a field has no Eq instance, use only the named function and derive nothing.
