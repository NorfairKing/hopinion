If the finding says the method restates its default, delete the method, and if that leaves no methods, keep the instance with no `where`: `instance Validity Foo`.
If the finding says the method calls every value valid, delete the method, and derive Generic for the type if it has no Generic instance; write `validate = trivialValidation` instead only when the type cannot have a Generic instance.
If the finding says the method names a binding that is not next to the instance, move that binding, with its signature and pragmas, to directly above or directly below the instance.
If the finding is about a top-level binding that the method names, rewrite that binding as the method is described below, and leave the method as it is.
Otherwise, write the method as one equation with no guards, no `where` and no `let`, of this shape: `validate x = mconcat [genericValidate x, declare "..." (...), ...]`.
Name the argument with a variable, or with an as-pattern such as `x@(Foo a b)` when the checks need its fields.
Make `genericValidate` of that same argument the first element of the list.
Put every check the method made before after it in the list, one element each, using `declare`, `decorate` or another `Validation`; a check that cases on the argument becomes one element that is a `case` expression.
